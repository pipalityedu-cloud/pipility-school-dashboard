# 🏫 Pipility School ERP

A monorepo School Enterprise Resource Planning (ERP) system built to manage school operations, empower teachers, and provide a public-facing web presence.

---

## 📁 Project Structure

```
apps/
├── apis/               # Backend REST API (Laravel)
├── school_dashboard/   # Teacher tools & admin dashboard (React)
└── school_front/       # Public-facing school website (React)
packeges/
|--ui/
|--emails/
|--lib/
```
